# Astra 0.1.0

**Birth** — the first tagged release: a working, verifiable end-to-end LM stack
implemented from scratch in NumPy, measured and reproducible.

## Highlights

- Custom from-scratch **byte-level BPE tokenizer** (vocab 800, round-trip exact on
  100% of strings incl. lone surrogates; 6.84 B/token on the toy corpus).
- **Transformer core** — learned token/position embeddings (RoPE), causal
  multi-head attention, RMSNorm pre-norm, SwiGLU feed-forward, PreNorm residuals,
  tied output head. Every backward path validated against float64 finite
  differences (H0.2).
- **Training loop** with task-shaped schedule (warmup → cosine decay), weight
  decay, grad clipping, frozen-val leak-gated evaluation.
- **Checkpointing**: deterministic `.npz` artifacts + run manifests
  (`checkpoints/phase0/report.json`); bit-identical across thread counts.
- **Basic text generation** built in (temperature-greedy reference inference,
  `evaluation/evaluate.py`).

## Evaluation summary

- Frozen validation split (163 decontaminated docs): **val_loss 2.535**, **ppl 12.62**,
  next-token accuracy **27.1%**, 4-gram repetition **0.0** over 200 generated tokens.
- Training to that point: 2000 steps, ~257 s on 8 CPU cores (~1,300 tok/s).
- Full report: `experiments/phase0/eval_report-v0.1.0.json` (checkpoint checksum tied).

## Known limitations

- Toy-scale model (~133k params) on synthetic structured data — **not** a real
  corpus model. The Phase-1 roadmap target (Astra-100M on a curated corpus) is
  future work.
- NumPy-only reference backend: inference ~92–218 tok/s (load-dependent);
  a GPU/optimized backend is required for scaling (ADR-0002).
- No latency/RAM/VRAM benchmarks yet; no evaluated quantized variants.
- Full benchmark suite deferred to Phase 2 (`docs/BENCHMARKS.md`).

## Data & reproducibility

- Data: `datasets/toy/manifest.json` (seeds 1/2/3, train 2000 docs, val 163 kept,
  eval 75 kept; n=13 decontamination; all splits `leak_free`).
- Hardware: 8-core CPU (x86_64), 29 GB RAM, no GPU. NumPy 2.3.5, Python 3.13.12.
- Reproducibility: 2000/2000 loss points bit-identical between `OPENBLAS_NUM_THREADS=1`
  and `=8` runs.
