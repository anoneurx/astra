# Astra 0.3.0

**Core** — the Phase-3 core-improvement release: a more capable transformer with
config variants and an ablation rig, a KV-cache streaming decoder, extended
context handling, a quantization preview, and benchmark harness v1.

## Highlights

- **More capable Transformer** (`python/astra/model/core.py`, `config.py`) —
  rank-1 config fields select transformer variants:
  - `norm_type`: `rmsnorm` (default) or `layernorm` (with bias),
  - `ffn_type`: `swiglu` (default, batched-Wu block) or `gelu` (2-projection FFN),
  - `pos_type`: `rope` (default) or `learned` (positional embedding).
  The default configuration (`rmsnorm` / `swiglu` / `rope`) is **bit-identical**
  to Astra 0.2.0: same logits, same loss, same every overlapping gradient.
  Backwards passes for all variants are float64 gradcheck-tested.
- **Ablation rig** (`tools/ablate.py`) — trains `baseline` vs `variant` on the
  same data and writes a comparison `summary.json` + `index.json` under
  `experiments/ablations/` (ignored by git). Param deltas recorded:
  LayerNorm +320, GELU −16,384, learned pos +4,096 vs the 133,440-param baseline.
- **Better inference** (`python/astra/inference/decoder.py`) — incremental
  KV-cache decoder (`KVCache` grows on demand), `decode_token` / `decode` with
  temperature, top-k, top-p, and sliding-window context. Per-position logits
  match the reference `generate()` to ~1e-7 within one window.
- **Context handling** — RoPE `_angles` extends on-the-fly beyond
  `max_seq_len`, the causal mask grows dynamically, and `generate(*, context_window=...)`
  decodes past the configured context. `eval` reference updated (`metrics.py`).
- **Quantization preview** (`python/astra/quantize.py`, `tools/quantize.py`) —
  in-place fp16 / bf16 / int8 weight quantization with per-tensor symmetric
  int8 scaling, bounded-error reporting (worst-case + mean abs per param), and
  sizes. fp16 halves weights; int8 quarters them (0.53 MB → 0.13 MB on the toy
  checkpoint). Tests bound fp32-vs-quantized forward-loss drift.
- **Benchmark harness v1** (`python/astra/evaluation/bench.py`,
  `tools/benchmark.py`, `benchmarks/suites/core-basic.json`) — manifest-driven
  suites with pluggable scorers (`val_ppl`, `decode_tokens_per_sec`,
  `repetition_fraction`), per-item thresholds and ops, and a JSON report tied to
  the checkpoint sha256. Gate result: `core-basic` PASS on `checkpoints/phase0/final.npz`.

## Test coverage

- `tests/test_model.py` — variant gradchecks (all float64, finite-difference vs
  analytic) plus `test_variant_arch_differences` (params, learned-pos influence).
- `tests/test_inference.py` — decoder-vs-reference equivalence, cache growth past
  `max_seq_len`, sliding-window bounds, learned-pos + GELU decode, extended-context
  generation.
- `tests/test_quantize.py` — round-trip sizes, error bounds, in-place mutation,
  int8 public/dispatch naming.
- `tests/test_benchmark.py` — threshold ops, val-ppl determinism, gate pass/fail
  end-to-end on a tiny checkpoint.

## Verification

- **Tests: 69/69 pass** (`make test`, OPENBLAS 8 threads).
- **Birth test: all PASS** — val_loss 3.9158, unchanged from Astra 0.2.0, i.e.
  no regression in the default model (`tools/birth_test.py`).
- Default-config bit-identity vs 0.2.0 verified by git-stash comparison.
- `ruff check` clean on all new files.

## Known limitations / deferred (Phase 3)

- **Learned positions + context > `max_seq_len`**: indexing out of bounds
  (pos-embed table is sized `max_seq_len`) — not yet handled. RoPE path handles
  long contexts.
- **Full-size core model (Astra-300M/700M)** — not trained; exit criteria for a
  released artifact require it. The toy checkpoint remains the reference.
- **Inference service (Python + Rust)** — decoder is Python-only; Rust engine is
  a later Phase-3 milestone.
- **Model registry v1** — checksum tooling (`tools/checksum.py`) + benchmark
  reports exist; formal registry entry not yet built.
- **ACTIVE(thresholded) benchmark suites** — `core-basic` thresholds are set
  from cast measurements (PASS on the toy checkpoint); promotion gates to be
  applied to the released model.

## Changes since 0.2.0

- 0.2.0 → 0.3.0: transformer variants + ablation rig, KV-cache inference decoder,
  dynamic context extension + `context_window`, quantization preview
