Phase 6 — Self-Improvement

Astra 0.9.0 Done

Automated candidate → evaluate → accept/reject → deploy loop with human approval gates, audit trail, and auto-rollback. Exit criteria all met.

  • Automatic evaluation (GateEngine: gain / no_regress / absolute)
  • Candidate model training (off active checkpoint)
  • Model comparison (deterministic base-vs-candidate CE)
  • Regression testing (no-forgetting gate)
  • Automatic checkpoint selection (registry promote)
  • Rollback (–rollback-drill + append-only audit trail)
  • Demo: target −0.775 CE, regression +0.009 CE → ACCEPT → promoted 0.9.0

Phase 8 — Evolution

Astra 1.x Engineering complete

Continuous controlled improvement with regression watch, drift detection, and rollback always available. Operator toolkit (coding phase) + durable memory compaction complete.

  • Operator tooling (continuous loop, drift watch, regression watch)
  • Long-term metrics store (append-only, per-promotion snapshots)
  • Drift detection (improving/stable/regressing + silent-drift flag)

  • Model lineage graphing (lineage() from registry superseded_by chain)
  • Rollback automation (--auto-rollback, audited)
  • Scheduled candidate training (continuous supervised window, > 1 week)
  • Durable memory growth (MemoryStore.compact(): prune + dedupe, audited)
  • Larger models

  • Better memory
  • More efficient learning
  • Hardware optimization
