06 Early-warning Eval generalization

The model is fed the 41-feature alert prefix and must emit the EARLY_WARNING label. Scores come from tools/eval_cyber.py on the held-out eval split and, for the last row, on the official KDDTest-21 test set (11,850 rows, 38 classes) imported as datasets/cyber/test21.txt.

v2 predicted normal for all rows (learned the 53.5% majority prior). v3 at 2800 changed behaviour on never-seen data: 21/25 normal rows exact, but cannot yet name attack classes exactly (0/83). The model learned the normal-vs-attack boundary — a real generalization signal.

08 Language — the prose model DONE · 5,400

The garbled chat ("hour nt er is is wyour.stra") came from the tiny toy "name" model — it only echoes memorized name-facts. The fix is the real 6M-prose model trained on clean public-domain prose (Project Gutenberg, US public domain). It ran as the astra-prose service: crash-safe, self-healing, on the external drive, auto-extending 1800 → 5400 steps.

  • ✓Crash-shield: self-healing runner — mount-guard + resume + save_every 25
